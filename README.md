# NSE Reports

A repository containing technical analysis reports for stocks listed on the National Stock Exchange of India (NSE).

## Overview

This repository stores daily technical analysis reports generated for NSE-listed stocks. The reports include various trading signals and technical indicators to help identify potential swing trading opportunities.

## Report Types

| Report Type | Description |
|-------------|-------------|
| `nse_quick_scan_*.txt` | Quick overview scans of NSE stocks |
| `professional_nse_analysis_*.txt` | Professional-grade technical analysis |
| `enhanced_nse_analysis_*.txt` | Enhanced analysis with additional indicators |
| `pattern_analysis_report_*.txt` | Chart pattern recognition analysis |
| `simple_pattern_analysis_report_*.txt` | Simplified pattern analysis |
| `ultimate_swing_setup_report_*.txt` | Swing trading setup recommendations |
| `enhanced_ultimate_swing_setup_*.txt` | Enhanced swing trading setups |
| `enhanced_ultimate_swing_setup_with_fundamentals_*.txt` | Swing setups with fundamental data |
| `Multi_Indicator_Swing_Signals_*.txt` | Multi-indicator swing trading signals |

## Technical Indicators Used

The reports analyze stocks using various technical indicators including:

- **Moving Averages**: SMA50, SMA200, Golden Cross detection
- **RSI (Relative Strength Index)**: Overbought/oversold conditions
- **MACD**: Bullish/bearish crossovers
- **Bollinger Bands**: Breakout detection
- **ADX**: Trend strength measurement
- **Stochastic Oscillator**: Recovery signals
- **OBV (On Balance Volume)**: Volume analysis
- **Ichimoku Cloud**: Trend and support/resistance analysis
